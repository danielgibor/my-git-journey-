# My Git Journey

- Git is a local tool to save versions of a program.
- GitHub is an online platform based on Git.
- git add adds files to a staging area and git commit takes files from the staging area and pushes them saves them as a version of a program.
- Branch is a parallel version of repository, we use it for features developing.
- Git push send local commits to GitHub.
- Git pull get changes from the remote repository and integrate them into the local system.
- A merge conflict takes place when we have two versions of one issue that we as human beings must deside which one of them is correct.
